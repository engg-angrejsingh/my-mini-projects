# ⌨️ Typing Game (Typing Speed Test)

A sleek, interactive typing speed test web application built with a modern **Spatial UI (Glassmorphism)** aesthetic. This project allows users to measure their typing speed in WPM (Words Per Minute) and tracks accuracy in real-time.

## ✨ Features

- **Real-Time WPM Calculation:** Instantly calculates your typing speed and accuracy at the end of the 60-second test.
- **Smart Idle Pause (New!):** If you stop typing for 5 seconds, the game automatically pauses the timer and waits for your next keystroke to resume.
- **Spatial UI Design:** Features a beautiful VisionOS-inspired frosted glass aesthetic, immersive background gradients, and premium drop shadows.
- **Dynamic Cursor:** A smooth, blinking cursor that tracks your exact position across words and lines.
- **Smart Word Navigation:** 
  - Prevents skipping empty words with the spacebar.
  - Allows backspacing to correct mistakes in the current or previous word.
- **Focus Mode Overlay:** When you click away from the typing area, the game automatically pauses, blurs the text, and displays a frosted glass "Click to Focus" overlay.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure.
- **CSS3:** Advanced styling using CSS Variables, Flexbox, backdrop-filters (blur), and responsive clamping.
- **JavaScript (ES6):** Core game logic, DOM manipulation, event listeners, and time/idle tracking.

## 🚀 How to Run

1. Clone the repository or download the project files.
2. Navigate to the `System_Typing` folder.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
4. Click on the game area and start typing to begin the timer!

## 🎮 How to Play

- **Start:** Just start typing! The 60-second timer begins on your first keystroke.
- **Pause:** Stop typing for 5 seconds, or click completely outside the typing box to pause. 
- **Correct Mistakes:** Use `Backspace` to fix incorrect letters before hitting space.
- **Next Word:** Hit `Space` to move to the next word.
- **Score:** When the time runs out, your WPM (Words Per Minute) score will be displayed.
