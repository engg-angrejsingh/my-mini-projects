# Gallery Hub 🖼️

A sleek, responsive, and dynamic image gallery web application. **Gallery Hub** serves as a visual portfolio to beautifully display a collection of images, featuring a smooth full-screen lightbox for an immersive viewing experience.

## ✨ Features

- **Dynamic Loading:** Images are loaded dynamically via JavaScript for a seamless experience.
- **Lightbox / Zoom Feature:** Click on any image to open it in an "Enlarged View" full-screen modal.
- **Responsive Grid:** The gallery layout automatically adapts to any screen size (mobile, tablet, desktop).
- **Modern UI:** Clean, minimalistic design that puts the focus on the photography/images.
- **Loading States:** Visually appealing loading indicators before images render.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Styling, grid layouts, and smooth animations/transitions.
- **JavaScript (Vanilla):** DOM manipulation, dynamic image fetching, and lightbox logic.
